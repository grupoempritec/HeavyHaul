# Elkin Moreno — Heavy Haul & Project Cargo LATAM (Landing Page)

## Contenido del paquete
- `index.html`: Landing page completa con diseño y estilos restaurados (Tailwind CSS, fuentes `Inter` y `Rajdhani`, clases `.blueprint-grid`, `.hazard-stripe`, `.glass-card`), simulador normativo Resolución 4959, galería filtrable de operaciones reales, taller en vivo, autodiagnóstico de riesgo y modales interactivos.
- `config.js`: Configuración central de WhatsApp, correo, LinkedIn, enlaces de pago (`checkoutUrl`) y webhook de leads (`leadWebhookUrl`).
- Imágenes de operaciones reales e imagotipo (`logo-elkin-moreno.png` y fotografías en campo).

## Despliegue rápido
1. Sube todos los archivos de esta carpeta a tu hosting, VPS o servicio de alojamiento estático manteniendo las rutas relativas.
2. Edita `config.js` para configurar tu `leadWebhookUrl` o tus enlaces de pago si deseas redirigir automáticamente tras inscribirse al taller.
